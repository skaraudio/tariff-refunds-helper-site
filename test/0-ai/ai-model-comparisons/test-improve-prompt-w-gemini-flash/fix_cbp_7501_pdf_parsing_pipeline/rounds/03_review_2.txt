   - Accurately parse line items: extract entryLineNumber, htsNumber, dutyRate, enteredValue, and dutyAmount.
   - Ensure isEligible is set to true if and only if at least one valid 9903.01.xx line item with non-zero duty refund is identified.
   - Calculate totalRefundAmount as the exact sum of duty paid across all eligible 9903.01.xx line items.
2. Add parse quality and confidence telemetry to the returned parser object:
   - parseConfidence: Float (0.00 to 1.00) computed as: (0.25 * header_present) + (0.45 * line_items_checksum_reconciliation) + (0.30 * matched_block_ratio), where checksum reconciliation compares sum of parsed line item duties against Form 7501 Box 39 / grand total if present.
   - parseQuality: String enum:
     - 'high': parseConfidence >= 0.85 and all identified lines parsed cleanly.
     - 'medium': parseConfidence between 0.60 and 0.84, IEEPA lines extracted with minor rate/value ambiguity.
     - 'low': parseConfidence between 0.20 and 0.59, severe column concatenation or line checksum mismatch.
     - 'failed': parseConfidence < 0.20 or unreadable document structure.
   - parseWarnings: Array of string codes, including 'DUTY_TOTAL_MISMATCH', 'CONCATENATED_TOKENS_RECOVERED', 'UNRECOGNIZED_LINE_FORMAT', 'MISSING_BLOCK_39_TOTAL', 'ZERO_DUTY_ON_ELIGIBLE_LINE'.
